# 픽셀 게임 비주얼 가드레일

이 문서는 StarJunkyard의 화면이 일반 모바일 앱처럼 보이지 않도록 막는 1.0 수락 기준이다. 상세 수치는 [마스터 GDD](../STARJUNKYARD_MASTER_GDD_KO.md)의 24장과 25장을 따른다.

## 한 줄 기준

첫 프레임을 3초간 본 사람이 생산성 앱이나 상점 앱이 아니라 **세로형 픽셀 게임의 전투 장면**이라고 즉시 인식해야 한다.

## 반드시 픽셀로 보이는 영역

- 전투 배경, 기지, 주인공, 드론, 적, 보스, 시설, 드롭, 파티클, 공격과 해체 효과
- 전투 HUD의 패널 외곽, 버튼 몸체, 아이콘, 진행 바, 숫자, 알림 너트
- 기지·창고·원정·시즌·상점 안에서 게임 세계를 나타내는 카드 프레임과 모든 아이템 이미지
- 온보딩 연출, 스토리 컷, 시즌 화면, 실제 플레이 광고 소재

위 요소는 1배율 PNG 원본, 승인 팔레트, nearest-neighbor, 정수 위치와 정수 확대를 사용한다. 일반 벡터 아이콘, SF 글래스 패널, 블러, 그라데이션 배경, 둥근 흰 카드 목록을 핵심 비주얼로 사용하지 않는다.

## 네이티브여야 하는 동작

- iOS의 뒤로 가기 스와이프, 시트 높이, 스크롤 감속, 결제·권한·구독 관리 화면
- Android의 시스템 뒤로 가기, edge-to-edge, 바텀 시트, 결제·권한·Play Games 화면
- Dynamic Type·fontScale에 대응하는 긴 설명문과 시스템 접근성 포커스

네이티브 동작은 유지하되 콘텐츠 표면은 픽셀 패널과 게임 팔레트로 구성한다. 운영체제 결제·권한 화면은 예외이며 게임 UI로 위장하지 않는다.

## 화면 구성 수락 기준

1. 360×800 논리 안전 구도를 중앙에 두고 남는 폭에는 환경만 확장한다.
2. 전투 영역이 안전 높이의 61%를 차지하며 첫 화면에서 적, 정비사, 드론, 기지 컨베이어가 동시에 보인다.
3. 하단 4탭은 픽셀 아이콘과 리벳 패널을 사용하되 플랫폼 내비게이션 동작은 보존한다.
4. 탭 직후 숫자만 변하지 않는다. 강화 세 번 안에 공구, 드론, 파편, 시설 중 하나의 픽셀 외형이 변한다.
5. 빈 상태도 일반 일러스트나 시스템 아이콘 대신 정비 중인 픽셀 오브젝트와 다음 행동을 보여 준다.
6. 본문 산세리프는 허용하지만 제목, 버튼, 전투 숫자, 아이콘과 패널은 도트 정체성을 유지한다.
7. 100%와 400% 확대에서 반투명 가장자리, 비정수 픽셀, 팔레트 밖 색, 1px 선 손상이 없어야 한다.

## 출시 차단 항목

- 핵심 화면이 흰 배경과 둥근 카드 목록 중심으로 보임
- 벡터 그림을 축소하거나 AI 이미지에 픽셀 필터만 적용함
- SpriteKit 또는 Canvas 위에 일반 시스템 버튼을 전투 조작처럼 올림
- 안티앨리어싱이 남은 스프라이트나 비정수 배율 확대
- 실제 게임에 없는 3D·퍼즐·가짜 조작을 스토어 또는 광고에 사용함
- 임시 도형·이모지·텍스트 아이콘이 릴리스 빌드에 남음
