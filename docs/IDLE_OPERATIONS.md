# 연구·제작·원정 작업 시스템

## 플레이 계약

- 연구와 제작은 무료 작업대 2칸을 공유한다.
- 원정은 무료 슬롯 1칸에서 독립적으로 진행한다.
- 기본 작업은 연구 5분, 재생 합금 제작 15분, 끝골목 원정 30분이다.
- 남은 시간이 3분 이하인 작업은 재화나 광고 없이 즉시 완료할 수 있다.
- 완료 보상은 사용자가 `회수`를 눌렀을 때 한 번만 지급된다.
- 작업 완료 시각과 수령 여부는 `GameSave`에 포함되어 로컬 백업과 Game Center 저장에 함께 보존된다.

## 시간과 알림

작업은 앱 실행 시간이 아니라 절대 완료 시각으로 계산한다. 마지막으로 관찰한 시각보다 5분 넘게 과거로 이동하면 `clockSuspect`가 되고, 마지막 정상 시각을 회복할 때까지 시작·완료·수령 판정을 보류한다. 이미 쌓인 작업과 보상은 삭제하지 않는다.

알림 권한은 첫 실행에 요청하지 않는다. 사용자가 10분 이상인 제작 또는 원정을 직접 시작한 뒤에만 현재 권한을 확인하며, 미결정 상태에서만 Apple 알림 권한을 요청한다. 거부 상태에서는 게임 진행을 막거나 설정 앱 이동을 강요하지 않는다.

## 현재 보상

| 작업 | 시간 | 보상 |
|---|---:|---|
| 재사용 프로토콜 I | 5분 | 영구 연구 기록 |
| 재생 합금 묶음 | 15분 | 합금 1 |
| 끝골목 잔해 수색 | 30분 | 고철 120, 부품 42, 회로 3 |

시설 화면 우측 상단의 `작업 관리`에서 세 작업의 시작·남은 시간·무료 완료·보상 회수를 처리한다.
