# 픽셀 설정 콘솔과 접근성

StarJunkyard의 설정은 전투 HUD에서 여는 게임 내 픽셀 콘솔이다. 일반 앱의 설정 폼처럼 보이지 않도록 피난처 단말기 프레임, 픽셀 기어 장식, 상태등과 명시적인 텍스트를 함께 사용한다. 기호만으로 기능을 추측하게 하지 않는다.

## 지원 설정

| 설정 | 기본값 | 적용 범위 |
| --- | --- | --- |
| 배경 음악 | 켬 | 합성 앰비언트 루프 재생 여부 |
| 효과음 | 켬 | 전투·복구·보스·설정 변경 효과음 |
| 햅틱 | 켬 | 전투·복구·보스·설정 변경 햅틱 |
| 모션 감소 | 끔 | 장식 애니메이션과 화면 전환 시간 |
| 화면 흔들림 감소 | 끔 | 피격·복구·보스 페이즈 흔들림 |
| 한 번 탭으로 실행 | 끔 | 전투 화면 탭을 현재 적 해체 동작으로 연결 |
| 플레이 데이터 공유 | 끔 | 개인정보 없는 개선 이벤트 기록 동의 |

설정은 `GameSettingsStore`와 `AnalyticsConsentStore`에 변경 즉시 저장한다. 과거 JSON에 새 필드가 없으면 안전한 기본값으로 마이그레이션한다.

## 게임 피드백

- 일반 공격과 적 해체는 짧은 효과음과 햅틱으로 결과를 알린다.
- 복구 성공은 별도의 상승음과 알림 햅틱을 사용한다.
- 보스 페이즈 파괴와 최종 해체는 서로 다른 강도의 피드백을 사용한다.
- `효과음`, `햅틱`, `화면 흔들림 감소` 설정은 각각 독립적으로 적용된다.
- `모션 감소`가 켜지면 장식 루프와 장면 전환 시간을 제거하되 입력과 전투 결과는 유지한다.

## 접근성과 현지화

- 모든 설정 행은 최소 312×48pt, 닫기 버튼은 216×52pt 입력 영역을 가진다.
- VoiceOver에는 7개 설정의 현재 상태를 한국어 또는 영어 문장으로 요약한다.
- 전투 화면은 `현재 적 해체`와 `설정 열기` 사용자화 동작을 제공한다.
- 전투 HUD의 설정 진입점도 48×44pt 투명 입력 영역을 가진다.
- 설정 이름과 상태는 한국어·영어 모두 텍스트로 표시하며, 아이콘은 보조 정보로만 사용한다.
