# StarJunkyard iOS

iOS/iPadOS 전용 StarJunkyard 저장소다. 루트의 `Project.swift`가 Xcode 프로젝트를 생성하며, UIKit이 앱 생명주기와 접근성 셸을 담당하고 SpriteKit이 360×800 픽셀 전투를 그린다. Android 프로젝트나 Android 빌드 의존성은 포함하지 않는다.
